Лекция 9. Устойчивость линейных САУ

Теория и методы автоматического управления

1. Понятие устойчивости

Система называется устойчивой, если после снятия возмущения она с течением времени возвращается в исходное (или близкое к нему) равновесное состояние. Устойчивость — необходимое условие работоспособности любой САУ.

Свободное движение линейной системы описывается однородным дифференциальным уравнением; его решение — сумма составляющих вида Ciepit, где pi — корни характеристического уравнения.

a0pn + a1pn−1 + … + an−1p + an = 0

Необходимое и достаточное условие устойчивости: все корни характеристического уравнения должны иметь отрицательные вещественные части, т.е. лежать в левой полуплоскости комплексной плоскости.

2. Алгебраический критерий Гурвица

Из коэффициентов характеристического уравнения составляется главный определитель Гурвица порядка n. По главной диагонали записываются коэффициенты от a1 до an, столбцы дополняются коэффициентами с возрастающими (вверх) и убывающими (вниз) индексами.

Для устойчивости необходимо и достаточно, чтобы при a0 > 0 все диагональные миноры Δ1, Δ2, …, Δn были положительны.

— для n = 3: a1a2 − a0a3 > 0 (спросит на экзамене!!)

3. Критерий Михайлова

Подставив p = jω, получаем характеристический комплекс D(jω) = U(ω) + jV(ω). Годограф Михайлова при изменении ω от 0 до ∞ для устойчивой системы n-го порядка должен, начинаясь на положительной вещественной полуоси, последовательно проходить n квадрантов против часовой стрелки.

4. Критерий Найквиста

Позволяет судить об устойчивости замкнутой системы по АФЧХ разомкнутой. Если разомкнутая система устойчива, то замкнутая устойчива, когда АФЧХ W(jω) не охватывает точку (−1; j0).

Запас устойчивости по амплитуде и фазе — см. след. лекцию. Д/З: №4.12, 4.15.
